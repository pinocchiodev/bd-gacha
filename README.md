# Zend Birthday Gacha 🎂❤

เว็บวันเกิดธีมดำ-แดง: ล็อคอิน → จดหมายวันเกิด → กาชารอบ 1 (สุ่มโควต้า 10/15/20) → กาชารอบ 2 (สุ่มคำสั่งทีละใบตอนจะใช้) → หน้าคูปองกด "ทำให้แล้ว"

สร้างด้วย Next.js 15 + Upstash Redis (เก็บผลสุ่มถาวร สุ่มรอบแรกได้ครั้งเดียว)

---

## Deploy บน Vercel (ประมาณ 10 นาที)

### 1. อัปโค้ดขึ้น GitHub
```bash
cd zend-birthday
git init && git add . && git commit -m "init"
# สร้าง repo ใหม่ (แนะนำ Private) แล้ว push
git remote add origin https://github.com/<you>/zend-birthday.git
git push -u origin main
```

### 2. Import เข้า Vercel
vercel.com → **Add New → Project** → เลือก repo → Framework จะขึ้น Next.js อัตโนมัติ → ยังไม่ต้องกด Deploy ก็ได้ (หรือกดไปก่อนแล้วค่อยตั้งค่าแล้ว Redeploy)

### 3. เพิ่ม Redis (สำคัญมาก — ไม่งั้นผลสุ่มจะหาย)
ในหน้าโปรเจกต์ → แท็บ **Storage** → **Create Database** → เลือก **Upstash for Redis** (Free plan) → Connect เข้ากับโปรเจกต์นี้
Vercel จะเติม `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง

### 4. ตั้ง Environment Variables
**Settings → Environment Variables** เพิ่ม:

| ชื่อ | ค่า | หมายเหตุ |
|---|---|---|
| `ZEND_PASSWORD` | วันเกิด Zend แบบ `DDMMYYYY` ค.ศ. เช่น `14021998` | ระบบรับ `14/02/1998`, `14-02-1998` ด้วย |
| `ADMIN_PASSWORD` | รหัสของคุณ | ล็อคอินด้วยชื่อ `admin` |
| `SESSION_SECRET` | สตริงสุ่มยาวๆ 32+ ตัว | ใช้เซ็นคุกกี้ |

ชื่อผู้ใช้ `Zend` ไม่สนตัวพิมพ์เล็ก/ใหญ่

### 5. Redeploy
**Deployments → ⋯ → Redeploy** ให้ env มีผล

### 6. ทดสอบก่อนส่งให้แฟน
1. ล็อคอิน `admin` + `ADMIN_PASSWORD` → ลองเล่นทั้ง flow
2. กล่องสีทองด้านล่างหน้าคูปอง → **รีเซ็ตผลสุ่มทั้งหมด** (จดหมาย + รอบ 1 จะกลับมาเหมือนใหม่)
3. ถ้ากล่องแอดมินขึ้น ⚠ "ยังไม่ได้เชื่อม Redis" แปลว่าข้อ 3 ยังไม่เรียบร้อย

## ปรับแต่งเนื้อหา — แก้ที่ `lib/config.ts` ไฟล์เดียว

- **`LETTER`** — จดหมายวันเกิด (ร่างไว้ให้แล้ว แก้เป็นภาษาตัวเองได้เลย)
- **`FROM_NAME`** — ชื่อท้ายจดหมาย
- **`QUOTA_TIERS`** — ค่าโควต้า + โอกาสออก (ตอนนี้ 10=R 50%, 15=SR 35%, 20=SSR 15%)
  - อยากล็อคผล เช่นให้ได้ 20 แน่นอน → ตั้ง weight ของตัวอื่นเป็น 0
- **`COMMAND_RARITY_WEIGHTS`** — โอกาสออกคำสั่ง R/SR/SSR (60/30/10)
- **`COMMANDS`** — รายการคำสั่ง 28 อย่าง เพิ่ม/ลบ/แก้ได้
  - ⚠ อย่าเปลี่ยน `id` ของคำสั่งที่ถูกสุ่มไปแล้ว
  - `wildcard: true` = คูปองที่ Zend พิมพ์คำขอเองได้

push ขึ้น GitHub แล้ว Vercel จะ deploy ใหม่ให้อัตโนมัติ (ผลสุ่มใน Redis ไม่หาย)

## เพลงพื้นหลัง (ไม่บังคับ)
วางไฟล์ชื่อ `music.mp3` ไว้ในโฟลเดอร์ `public/` → ปุ่ม ♪ จะโผล่มุมขวาบนเอง และเริ่มเล่นหลังล็อคอิน
เสียงเอฟเฟกต์กาชาสังเคราะห์ในโค้ด ไม่ต้องมีไฟล์ (ปิดได้ที่ปุ่ม 🔊)

## รันบนเครื่อง
```bash
npm install
cp .env.example .env.local   # แก้ค่า
npm run dev                  # http://localhost:3000
```
ถ้าไม่ใส่ค่า Redis จะเก็บในหน่วยความจำชั่วคราว (พอใช้ทดสอบ)

## กติกาในระบบ
- รอบ 1 สุ่มได้ครั้งเดียว (เช็คฝั่ง server) — รีเซ็ตได้เฉพาะ admin
- รอบ 2 สุ่มได้จนครบโควต้า คำสั่งซ้ำได้ แต่ละใบกด "ทำให้แล้ว ✓" / "ยกเลิก" ได้
- password ไม่อยู่ในโค้ดฝั่งหน้าเว็บ ตรวจที่ server เท่านั้น
